# 🚀 Como Hospedar Grátis a Plataforma Geradora de Conteúdo

Este repositório contém o código completo em Python (`app.py`) para executar e gerenciar a sua **Plataforma Geradora de Roteiros, Prompts, Posts e Devocionais**.

## 📌 Opções Gratuitas de Hospedagem em Nuvem

De acordo com as melhores práticas de deploy para Python, você pode publicar essa aplicação de forma **100% gratuita** e sem necessidade de cartão de crédito em duas grandes plataformas:

---

### 1. Streamlit Community Cloud (Recomendado)
* **Site:** [https://share.streamlit.io](https://share.streamlit.io)
* **Como Fazer o Deploy:**
  1. Crie uma conta gratuita no GitHub (se ainda não tiver).
  2. Crie um novo repositório no GitHub e envie os arquivos `app.py` e `requirements.txt`.
  3. Acesse o **Streamlit Community Cloud**, faça login com seu GitHub e clique em **"New app"**.
  4. Selecione o repositório e o arquivo `app.py` e clique em **"Deploy"**.
  5. Pronto! A aplicação estará online com um link público que você pode acessar de qualquer celular ou computador.

---

### 2. Hugging Face Spaces
* **Site:** [https://huggingface.co/spaces](https://huggingface.co/spaces)
* **Como Fazer o Deploy:**
  1. Crie uma conta gratuita no **Hugging Face**.
  2. Vá em **Spaces** -> **Create new Space**.
  3. Escolha o SDK **Streamlit**.
  4. Suba os arquivos `app.py` e `requirements.txt`.
  5. A plataforma compilará e colocará sua aplicação online instantaneamente com suporte a 2 vCPUs e 16 GB de RAM no plano grátis.

---

## 💻 Como Executar Localmente na sua Máquina

1. Instale o Python 3.10+ no seu computador.
2. Abra o terminal e instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```
3. Execute a aplicação:
   ```bash
   streamlit run app.py
   ```
4. O navegador abrirá automaticamente no endereço `http://localhost:8501`.
